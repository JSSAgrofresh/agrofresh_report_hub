      5 · Cómo se actualiza

      De la idea a producción

      Un cambio nunca se prueba en producción: primero se escribe y se revisa aparte, y recién después llega a los clientes.

      Se programa

      El cambio se escribe en una rama aparte, sin tocar lo que usan los clientes. Cada avance genera una vista previa para probar.

      Se aprueba

      Cuando está listo se fusiona con la versión estable, llamada main. Queda registrado quién y cuándo.

      Se publica la pantalla

      Vercel toma la versión estable y publica solo la pantalla nueva. Nadie tiene que hacer nada.

      Se actualiza el servidor

      En el computador de la oficina se trae la versión nueva, se actualiza la base si hace falta y se reinicia el cerebro.

      Detalle técnico: los comandos del servidor (PowerShell)

      Se repiten en cada actualización:

      git checkout main; git pull origin main
      .venv\Scripts\python.exe scripts\migrar.py 0072_presentacion_remota.sql
      Stop-ScheduledTask -TaskName "AgroFresh Report Hub - Backend"; Start-Sleep 3; Start-ScheduledTask -TaskName "AgroFresh Report Hub - Backend"

      El segundo comando es un ejemplo: solo se corre cuando el cambio trae una migración de la base.

      6 · Qué nos aporta

      Lo que cambia para AgroFresh

      Cuatro cosas que el sistema hace mejor que el trabajo a mano.

      Eficiencia

      El informe llega al correo, el sistema lo lee solo y queda listo para aceptarse. Nadie vuelve a escribir los resultados.

      Dónde se ve

      Bandeja de informes del correo.

      Trazabilidad

      Cada solicitud tiene su número único y cada carga de datos queda con quién y cuándo. Si algo salió mal, se puede deshacer.

      Dónde se ve

      Número OT y botón «Deshacer».

      Comunicación con el cliente

      Cada cliente ve sus resultados y descarga sus informes cuando quiere, en su propia pantalla, y solo los suyos.

      Dónde se ve

      Portal de clientes.

      Calidad del dato

      Los nombres se ordenan contra un listado oficial. Lo dudoso se revisa antes de entrar, y por eso los datos se pueden comparar.

      Dónde se ve

      Homogeneización y filas pendientes.
